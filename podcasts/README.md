# Podcasturi / Podcasts – Enterobacterales, Vibrionaceae, Campylobacter/Helicobacter și bacilii gram-negativi nefermentativi

Two complete podcast series (two-host dialogue scripts) built from the synoptic table
*„Enterobacterales nefermentativi – tabel sinoptic”*. Each series covers the whole document:
taxonomy, habitat, general characters, antigens, virulence, clinical significance, the 5-step direct
lab diagnosis (collection → microscopy → culture → identification 4a–4i → AST), serology, treatment,
plus all 7 annex tables and a final quiz. Content flagged in the source as "beyond the course
materials" (MALDI-TOF, WGS, EUCAST, Acinetobacter, Campylobacter, etc.) is marked in the dialogue as
the "modern layer" / „stratul modern”.
